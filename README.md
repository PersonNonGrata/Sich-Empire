ІМПЕРІЯ СІЧ

> Альтернативна історія. Політична стратегія. Психологічне сходження.



Імперія Січ — інтерактивна історико-політична гра, у якій гравець бере на себе роль новообраного Гетьмана наймогутнішої держави Східної Європи.

Це держава, створена козаками після перемоги, яка змінила хід історії. Січ не лише здобула незалежність, а згодом підкорила Річ Посполиту та Московію, перетворившись на імперію.

Через століття після її становлення новий Гетьман успадковує державу, створену перемогами попередніх поколінь.

Але разом із величчю він успадковує їхні борги, конфлікти, страхи, союзи, міфи та незавершені рішення.

І тепер держава починає відповідати на його вибір.

Світ

Імперія Січ

Альтернативна держава, що виникла з перемоги козацького світу.

Її історія охоплює приблизно два століття:

перемога → становлення → завоювання → централізація → модернізація → імперська велич → внутрішні суперечності → нове покоління влади.

До моменту початку кампанії Січ стала величезною державою з різними землями, традиціями та політичними силами.

Її фундамент складається з кількох суперечливих принципів:

козацька свобода;

сильна держава;

військова традиція;

місцеве самоврядування;

імперська централізація;

модернізація;

право;

традиція;

торгівля;

культура;

освіта.


Головна проблема імперії полягає в тому, що всі ці принципи можуть бути одночасно правильними, але не завжди сумісними.

Саме на цьому виникає політика.

Це дозволяє створювати відчуття справжнього історичного часу.

Політична воля

Гетьман має особливий ресурс:

Політичну волю.

Це здатність проводити складні рішення попри політичний опір.

Політична воля відрізняється від грошей.

Скарбниця
→ матеріальна спроможність держави

Політична воля
→ спроможність Гетьмана проводити політично складні рішення

Рішення можуть мати політичну ціну.

Наприклад:

42 → 37

Але за цим числом стоїть політична реальність:

Числові значення не повинні бути головним предметом уваги гравця.

---

Психологічні напруги

Гра відстежує фундаментальні суперечності:

Свобода ↔ Порядок

Традиція ↔ Творення

Знання ↔ Дія

Влада ↔ Відповідальність

Співчуття ↔ Домінування

Стабільність ↔ Зміна

Гравець може роками рухатися в одному напрямку.

Але система поступово створює ситуації, де цей шлях починає випробовувати сам себе.

Тінь архетипу

Кожен стиль правління має власний ризик.

Наприклад:

Архітектор

Сила: створює інституції.

Тінь: може почати бачити людей лише як елементи системи.

Охоронець

Сила: захищає державу.

Тінь: може перетворити захист на страх перед змінами.

Володар

Сила: здатність концентрувати владу.

Тінь: влада може стати самоціллю.

Гра не повідомляє гравцю, яким він «повинен» бути.

Вона показує наслідки його власного стилю.

Принципи проєкту

1. Рішення мають наслідки

Якщо гра говорить, що рішення має майбутній наслідок, він повинен реально існувати в GameState.

2. Світ пам'ятає

Попередні рішення повинні змінювати майбутню гру.

3. Час має значення

Майбутні події не показуються до їхнього часу.

4. Психологія важливіша за оцінку

Гра досліджує, ким стає Гетьман, а не просто визначає, чи був його вибір «правильним».

5. Немає єдиного правильного стилю правління

Різні шляхи повинні породжувати різні світи.

6. Наслідки повинні бути конкретними

Не:

> «Це рішення може мати наслідки.»



А:

> «Через два роки наслідок цього рішення змінив стан армії.»



7. Історія повинна виникати з гри

Сюжет не повинен повністю диктуватися наперед.

Він формується через взаємодію:

контент
+
GameState
+
рішення
+
пам'ять
+
психологія
+
політика
=
історія конкретного Гетьмана

Структура даних

При додаванні нового сценарію перевага надається data-driven підходу.

Умовна структура:

{
  id: "scenario_example",
  year: 1849,
  sequenceOrder: 20,

  conditions: [...],

  choices: [
    {
      id: "choice_a",

      consequences: [...],

      psychologicalSignals: [...],

      politicalEffects: [...],

      memoryTags: [...],

      scheduledConsequences: [...]
    }
  ]
}

Сценарій не повинен самостійно керувати GameState.

Він описує ситуацію та можливі наслідки.

Рушій виконує їх.
